# Monster Maker Studio

Deterministic 64x64 monster generator with:
- epoch × kingdom × culture axes
- style preset + palette mode axes
- mobile-first single-file HTML app
- fixed-part rendering
- sprite strip with four poses: idle, attack, recoil, cast

This tool is intentionally deterministic and cartridge-era in structure: no shaders, no AI image generation, no procedural mesh generation.
